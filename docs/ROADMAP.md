# 路线图（Roadmap）

> v0.1 已发布，当前功能见 [README 特性列表](../README.md)；版本历史见 [CHANGELOG](../CHANGELOG.md)；设计原则见 [DESIGN.md](DESIGN.md)。

## v0.2计划 — 更完整的 git 工作区能力

- [ ] 分支管理 UI：创建 / 切换 / 查看分支列表；
- [ ] stash（暂存）与恢复；
- [ ] 交互式选择文件 / 代码块加入提交（部分暂存）；
- [ ] 冲突检测与合并状态的可视化提示；
- [ ] 提交详情查看（含完整 message、改动统计）；
- [ ] 支持撤销最近一次草稿提交（软重置）。

## v0.3计划 — 覆盖需构建的前端工程

- [ ] 可配置构建命令（如 `npm install` / `npm run build`）与构建日志流式输出；
- [ ] 构建产物目录的预览映射；
- [ ] 依赖缓存与工作区环境管理；
- [ ] 简单后端服务进程的启停托管（可选，谨慎授权）。

## v1.0计划 — Web 内置 LLM 对话 Agent

把当前形态（对话 AI 在工具之外改动工作区，Web 工具负责审查与落盘）升级为「对话也收进工具」的形态：在单页内形成「对话 → 改代码 → 看 diff → 预览 → 提交」闭环。

- [ ] 模型配置：接入 OpenAI 兼容接口 / 自托管模型，密钥本地保存；
- [ ] Function / Tool Calling：模型调用受控接口读取文件、应用补丁、执行受限 git 操作；
- [ ] 改动以补丁（patch）形式提出，用户逐文件 / 逐块审批后才落盘；
- [ ] 多轮上下文携带工作区状态与最近 diff；
- [ ] 审批模式（全部人工确认）与半自动模式（模型可直接改草稿、人工只审提交）；
- [ ] 依然保持模型可替换、数据自托管。

## v1.x — 协作与工程化

- [ ] PWA：离线壳、消息推送（构建完成 / 提交成功通知）；
- [ ] Webhook：仓库更新、CI 结果回传；
- [ ] 多用户与只读 / 可写角色（当前定位个人单用户）；
- [ ] 操作审计与回滚增强；
- [ ] 浏览器扩展 / 系统分享入口，便于从聊天 App 一键发送需求。
